## 5. 智能项圈使用说明（规划功能，尚待开发与验收）

### 5.1 智能项圈是什么

智能项圈计划作为宠物档案的配套设备，通过设备传感器采集经支持的宠物活动或环境数据，并在具备相应定位、通信和后台服务的条件下，将数据传送至 PetHome。

计划涉及的能力包括：

- 定位信息及最近一次可信位置
- 定位历史或活动轨迹（以设备实际记录和上传的数据为准）
- 活动传感器数据
- 温度等设备实际配备的传感器数据
- 设备在线状态与异常提醒
- 经主人授权的舒适护理控制

设备实际能提供哪些数据，取决于硬件配置、传感器能力、网络连接和软件实现。项圈测得的温度不应直接等同于宠物核心体温，也不能作为疾病诊断依据。

### 5.2 将项圈与宠物档案绑定

规划中的绑定流程如下：

1. 登录 PetHome 账号。
2. 进入对应宠物的档案页面。
3. 选择“添加设备”或类似入口。
4. 按正式版本要求扫描设备二维码或输入设备编号。
5. 阅读设备绑定和数据授权说明，确认将设备关联到当前宠物。
6. 等待系统完成设备身份校验和绑定结果反馈。
7. 返回宠物档案，核对设备名称、编号及绑定对象。

注意事项：

- 只有宠物主人或拥有相应管理权限的家庭成员，才应执行绑定、解绑等管理操作。
- 不要将设备编号、配对码或账号凭据公开分享。
- 如果设备已绑定其他宠物或账号，应先通过正式的解绑、转移或客服流程处理，不要强行重复绑定。

### 5.3 查看宠物定位和历史轨迹

在定位功能正式上线且设备具备定位与通信能力后，规划中的查看方式为：

1. 打开对应宠物档案。
2. 进入“设备”或“定位”页面。
3. 查看设备最近一次成功上传的位置及其记录时间。
4. 如果系统已保存连续定位记录，可选择日期或时间范围查看历史轨迹。
5. 查看定位状态、数据更新时间和可能的精度提示。

定位使用注意事项：

- 定位可能受室内环境、建筑物遮挡、天气、设备电量和网络状况影响。
- 页面应区分“实时位置”和“最近一次成功上报的位置”，不能把旧位置误认为实时位置。
- 如果设备离线或长时间未上报，应先检查设备状态，不要仅凭最后位置判断宠物当前所在位置。
- 定位信息属于敏感信息，只向获得授权的账号展示；分享位置前应确认接收对象和授权范围。

### 5.4 设置智能电子围栏和接收提醒

电子围栏计划采用主人设置范围、系统按规则判断的方式，并非 AI 自动决定宠物是否走失。功能上线后的预期流程为：

1. 进入宠物档案中的“安全区域”或“电子围栏”页面。
2. 在地图上选择区域中心并设置合适的范围。
3. 检查地图位置和范围是否正确。
4. 阅读提醒规则，确认越界提醒的接收账号和通知方式。
5. 保存设置，并确认系统显示设置成功。
6. 后续查看围栏状态和提醒记录。

注意事项：

- 电子围栏判断依赖定位数据；定位漂移或上报延迟可能造成误报或漏报。
- 应结合定位更新时间和可信度判断提醒，不应把单次定位异常直接视为宠物已经走失。
- 家庭共享时，只有拥有相应权限的成员才能修改围栏和提醒设置。
- 在实际测试、误差评估和通知链路验收完成前，不应将电子围栏作为唯一的宠物安全保障。

### 5.5 查看活动、温度等传感器数据

在对应传感器和数据上传功能完成联调后，用户计划可以：

1. 打开宠物档案并进入智能项圈数据页面。
2. 查看设备在线状态、数据更新时间和传感器类型。
3. 选择日期或时间范围，查看已成功上传的活动数据或趋势。
4. 如设备配备温度传感器，可查看对应测量值、单位和采集时间。
5. 遇到数据中断、明显异常或长时间未更新时，先检查设备佩戴、供电和网络状态。

数据解释边界：

- 活动数据是传感器记录或算法估算结果，可能受到佩戴位置、宠物体型和运动环境影响。
- 项圈温度读数受测量位置和环境影响，不等于宠物核心体温。
- 传感器趋势和系统提示仅供日常观察参考，不能替代兽医检查或专业诊断。
- 只有经过数据质量检查和实际验证的指标，才能作为正式用户功能展示。

### 5.6 使用舒适护理功能

舒适护理（例如项圈震动反馈）属于需要单独进行硬件安全评估的规划能力。功能上线前，必须明确适用条件、强度上限、最长运行时间、人工控制方式和异常保护策略。

规划中的使用流程为：

1. 由宠物主人主动进入对应宠物的护理控制页面。
2. 阅读安全说明，确认宠物适合使用该功能，且设备状态正常。
3. 选择经过安全验证的模式、强度和时长。
4. 由主人明确确认后启动，不应由 AI 分析结果自动触发。
5. 运行期间，主人应能随时发出停止指令。
6. 页面应显示运行状态，并在停止后反馈结果。

护理功能应具备至少三种停止机制：

- **到时停止：** 达到主人设定且经过安全验证的最长运行时间后，设备自动停止。
- **主人停止：** 主人可以主动发出停止指令；设备收到有效指令后应尽快关闭护理输出。
- **异常停止：** 当设备检测到已定义的异常，或无法确认安全运行条件时，应停止输出，并在通信可用时向主人报告异常。

安全要求：

- 不得把震动或舒适护理宣传为治疗疾病、替代兽医诊疗的手段。
- 不得在未验证强度、时长和硬件安全性前开放实际控制。
- 通信中断、状态不明或控制指令未获确认时，应采用安全优先的停止策略。
- 应保留必要的操作记录和异常记录，便于追溯。
- 宠物出现明显不适时，主人应立即停止使用并观察；必要时咨询兽医。

### 5.7 多宠物和家庭共享权限

平台规划支持一个账号管理多个宠物档案，并允许主人邀请家庭成员共同查看部分信息。功能上线后的权限设计应遵循最小必要原则：

- **宠物主人/管理员：** 管理宠物档案、设备绑定、家庭成员邀请、权限分配及关键安全设置。
- **家庭成员：** 仅查看或操作主人明确授权的宠物和功能。
- **受限成员：** 只能访问被授权的部分信息，不应默认拥有设备解绑、成员管理或护理控制权限。

使用前应：

1. 核对被邀请成员的账号身份。
2. 明确选择共享的宠物和数据范围。
3. 只授予完成任务所需的权限。
4. 定期检查家庭成员列表，及时撤销不再需要的授权。

定位、历史轨迹和护理控制属于较敏感的功能，应单独设置权限，不应因为加入家庭共享就自动向所有成员开放。

### 5.8 设备离线、定位异常和安全注意事项

遇到设备异常时，可按以下顺序排查：

1. 检查项圈是否正确佩戴、供电是否正常。
2. 检查设备是否开机，以及页面显示的最后更新时间。
3. 检查手机或设备所在环境的网络与定位条件。
4. 如果数据仍未更新，记录设备编号、发生时间和页面提示，并通过正式反馈渠道报告。
5. 不要把长时间未更新的位置当作宠物当前实时位置。
6. 如果舒适护理状态不明确，应优先停止使用，不要反复发送启动指令。

正式发布前，项目还需完成设备断网、低电量、定位漂移、数据延迟、错误绑定、越权访问和异常停止等测试。未通过安全验收的功能不得向普通用户开放。

## 7. AI 功能说明

PetHome V2.0 的 AI 能力目前属于规划方向。只有在模型或服务真实接入、功能测试通过并完成验收后，才会在本节提供用户操作说明。

未来可能研究的方向包括活动或行为识别、趋势分析、异常变化提示和走失线索辅助匹配。相关能力需要真实数据、标注、模型训练或规则基线、独立测试和效果评估。

电子围栏和家庭权限属于规则与权限管理，不应包装成 AI 功能。AI 输出不得自动触发项圈舒适护理。涉及健康、用药、救助、定位和图片匹配的 AI 输出均应明确能力边界；不得将 AI 辅助信息当作专业诊断或自动决策。

正式发布前应补充并核验：

- 个人信息收集和使用范围

- 账号安全和风险反馈渠道
