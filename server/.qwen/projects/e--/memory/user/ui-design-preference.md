# UI 设计偏好

**规则**: 宠物网站页面应采用温馨可爱风格设计

**Why**: 用户明确要求宠物网站整体风格要温馨可爱，符合宠物主题

**How to apply**: 
- 使用柔和的色彩搭配（粉色、浅黄、米色等）
- 圆角设计，避免尖锐边角
- 使用可爱的图标和插图
- 字体选择圆润友好的字体
- 整体布局要亲切、不严肃
