# 任务执行顺序偏好

**规则**: 按顺序执行任务，不要并行处理

**Why**: 用户希望任务按顺序逐一完成，便于跟踪进度和确认每个步骤的结果

**How to apply**: 
- 接到多个任务时，明确告知用户任务列表
- 按顺序逐一执行，每完成一个向用户确认
- 不要同时开始多个独立任务
- 等待用户确认后再进行下一步
